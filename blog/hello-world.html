Hello, world — and why this site exists

Every developer ends up rebuilding their personal site eventually. This is my version: a simple, fast, hand-written corner of the internet — no framework, no build step, just HTML and CSS hosted on GitHub Pages.

What you'll find here

  • Apps — BambooNode, my privacy-first notes and file manager, plus whatever comes next.
  • Dev notes — things I learn while building: Kotlin, Jetpack Compose, MVI architecture, and the occasional debugging war story.
  • Release updates — changelogs and the reasoning behind product decisions.

Why no framework?

Because the site should be as boring and dependable as the apps I build. Plain static pages load fast, never break, and will still render in ten years. The simplicity is the feature.

If you want to say hi, my inbox is always open: weijaky@gmail.com

Focus on yourself, not others.
