Política de Privacidade do BambooNode

Última atualização: 26 de julho de 2026

Data de entrada em vigor: 26 de julho de 2026

1. Introdução

O BambooNode ("nós", "nosso" ou "nos") é um aplicativo de anotações e gerenciamento de arquivos desenvolvido para dispositivos Android. Esta Política de Privacidade explica como coletamos, usamos e protegemos suas informações pessoais quando você usa nosso aplicativo.

Nós nos comprometemos a proteger sua privacidade e garantir a segurança de seus dados. Esta política se aplica a todos os usuários do BambooNode.

2. Quais informações coletamos?

O BambooNode é projetado como um aplicativo focado na privacidade. Não coletamos nenhuma informação pessoal sem seu conhecimento e consentimento explícitos.

2.1 Dados locais

Todas as anotações e arquivos que você cria ou importa usando o BambooNode são armazenados localmente em seu dispositivo. Isso inclui:

  • Conteúdo de texto de suas anotações
  • Imagens e anexos que você adiciona às anotações
  • Metadados de arquivos (nomes, tamanhos, datas de modificação)
  • Informações de tags para organizar anotações
  • Configurações e preferências do aplicativo

Esses dados são armazenados no armazenamento do seu dispositivo (pasta Downloads ou outro local selecionado) e nunca são transmitidos para nossos servidores.

2.2 Dados opcionais de sincronização Git

Se você habilitar a função opcional de sincronização Git, suas anotações e arquivos podem ser enviados para um repositório Git remoto que você configura. Isso é feito a seu critério e requer que você forneça:

  • URL do repositório remoto
  • Credenciais de autenticação (nome de usuário/senha ou token de acesso)

Suas credenciais Git são armazenadas localmente no seu dispositivo usando as preferências seguras do Android e nunca são transmitidas para nossos servidores.

2.3 Informações do dispositivo (para solução de problemas)

Quando você usa a função de feedback, você pode fornecer opcionalmente informações do dispositivo para nos ajudar a solucionar problemas. Isso pode incluir:

  • Versão do Android
  • Modelo do dispositivo
  • Versão do aplicativo

Essas informações só são enviadas quando você envia feedback explicitamente e são usadas exclusivamente para melhorar o aplicativo.

3. Como usamos suas informações?

Nós usamos suas informações apenas para os seguintes fins:

  • Fornecer e manter a funcionalidade principal do BambooNode
  • Habilitar o armazenamento local e a gestão de suas anotações e arquivos
  • Facilitar a sincronização Git opcional (se habilitada)
  • Melhorar o aplicativo com base no feedback (se fornecido)
  • Garantir a segurança e integridade de seus dados

4. Armazenamento e segurança de dados

4.1 Armazenamento local

Suas anotações e arquivos são armazenados localmente no seu dispositivo Android. Você pode escolher o local de armazenamento (por exemplo, pasta Downloads) durante a configuração inicial.

4.2 Medidas de segurança

Implementamos medidas de segurança razoáveis para proteger seus dados, incluindo:

  • Armazenamento seguro de credenciais Git usando preferências criptografadas do Android
  • Operações de arquivos usando o Framework de Acesso ao Armazenamento (SAF) do Android para gerenciamento seguro de arquivos
  • Atualizações regulares para abordar vulnerabilidades de segurança

No entanto, nenhum método de armazenamento é completamente seguro. Não podemos garantir a segurança absoluta de seus dados.

5. Compartilhamento de dados

Nós não compartilhamos, vendemos ou alugamos suas informações pessoais a terceiros para qualquer fim.

A única exceção é quando você habilita a sincronização Git, caso em que seus dados são transmitidos para o repositório Git remoto que você especifica. Não temos controle sobre como os provedores de Git de terceiros tratam seus dados.

6. Permissões

O BambooNode requer as seguintes permissões para funcionar:

  • INTERNET: Necessária para sincronização Git e funções de feedback
  • READ_EXTERNAL_STORAGE: Necessária para ler anotações e arquivos do seu dispositivo
  • WRITE_EXTERNAL_STORAGE: Necessária para salvar anotações e arquivos no seu dispositivo
  • MANAGE_EXTERNAL_STORAGE: Necessária para acesso completo ao armazenamento externo no Android 11+

Todas as permissões são solicitadas em tempo de execução e você pode revogá-las a qualquer momento por meio das configurações do seu dispositivo. No entanto, a revogação de certas permissões pode afetar a funcionalidade do aplicativo.

7. Seus direitos

Você tem os seguintes direitos com relação aos seus dados:

  • Acesso: Você pode acessar todas as suas anotações e arquivos diretamente pelo aplicativo
  • Modificação: Você pode editar, renomear ou excluir suas anotações e arquivos a qualquer momento
  • Exportação: Suas anotações são armazenadas como arquivos Markdown (.md) ou texto (.txt) padrão, que você pode exportar usando qualquer gerenciador de arquivos
  • Exclusão: Você pode excluir todos os seus dados desinstalando o aplicativo e removendo os arquivos do seu dispositivo

8. Conformidade com o Regulamento Geral de Proteção de Dados da UE (GDPR)

O BambooNode está em conformidade com o Regulamento Geral de Proteção de Dados da União Europeia (GDPR) para usuários na União Europeia e no Espaço Econômico Europeu (EEE).

8.1 Controlador de Dados

O BambooNode atua como controlador de dados para quaisquer dados pessoais processados através do aplicativo. O controlador de dados é responsável por garantir que seus dados pessoais sejam processados em conformidade com o GDPR.

8.2 Base Legal para Processamento

Processamos seus dados pessoais com base nas seguintes bases legais:

  • Consentimento: Quando você fornece explicitamente informações do dispositivo para solução de problemas através da função de feedback
  • Necessidade Contratual: Quando você usa a sincronização Git, processamos os dados necessários para fornecer o serviço solicitado
  • Interesses Legítimos: Podemos processar dados de uso anônimos para melhorar a estabilidade do aplicativo e a experiência do usuário

8.3 Retenção de Dados

Seus dados locais (anotações, arquivos, configurações) são retidos no seu dispositivo até você optar por excluí-los ou desinstalar o aplicativo. Os dados de feedback, se fornecidos, são retidos apenas pelo tempo necessário para resolver o problema relatado e depois são excluídos.

8.4 Transferências Internacionais de Dados

Se você habilitar a sincronização Git, seus dados podem ser transferidos para servidores localizados fora da UE/EEE. Não somos responsáveis pelas práticas de tratamento de dados dos provedores Git terceiros. Revise a política de privacidade do provedor Git escolhido antes de habilitar a sincronização.

8.5 Direitos Adicionais dos Usuários da UE/EEE

Além dos direitos listados na Seção 7, os usuários da UE/EEE têm os seguintes direitos sob o GDPR:

  • Direito de Retificação: Você pode solicitar a correção de dados pessoais imprecisos
  • Direito ao Apagamento ("Direito de Ser Esquecido"): Você pode solicitar a exclusão de seus dados pessoais
  • Direito à Restrição do Processamento: Você pode solicitar que limitemos o processamento de seus dados pessoais
  • Direito à Portabilidade de Dados: Você pode receber seus dados pessoais em um formato estruturado e legível por máquina
  • Direito de Oposição: Você pode se opor ao processamento de seus dados pessoais com base em interesses legítimos
  • Direito de Retirar o Consentimento: Você pode retirar seu consentimento a qualquer momento sem afetar a legalidade do processamento baseado no consentimento antes de sua retirada

Para exercer esses direitos, entre em contato conosco em weijaky@gmail.com. Responderemos à sua solicitação dentro de 30 dias, conforme exigido pelo GDPR.

8.6 Autoridade Supervisora

Se você acredita que nosso processamento de seus dados pessoais infringe o GDPR, você tem o direito de apresentar uma reclamação à sua autoridade supervisora local ou à autoridade supervisora do local onde você reside.

9. Alterações nesta Política de Privacidade

Podemos atualizar esta Política de Privacidade de tempos em tempos. Nós vamos notificá-lo sobre quaisquer alterações publicando a nova Política de Privacidade nesta página e atualizando a data de "Última atualização".

O uso contínuo do BambooNode após qualquer alteração nesta política constitui sua aceitação da política atualizada.
