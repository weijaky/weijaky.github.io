BambooNode 개인정보 처리방침

최종 업데이트: 2026년 7월 26일

시행일: 2026년 7월 26일

1. 소개

BambooNode("우리", "저희" 또는 "본 앱")은 Android 기기용으로 개발된 노트 작성 및 파일 관리 애플리케이션입니다. 본 개인정보 처리방침은 사용자가 본 애플리케이션을 사용할 때 개인정보를 어떻게 수집, 사용, 보호하는지 설명합니다.

우리는 사용자의 개인정보를 보호하고 데이터의 안전성을 보장하기 위해 최선을 다합니다. 본 방침은 BambooNode의 모든 사용자에게 적용됩니다.

2. 어떤 정보를 수집합니까?

BambooNode는 개인정보 보호에 중점을 둔 애플리케이션으로 설계되었습니다. 사용자의 명시적인 동의 없이는 어떠한 개인정보도 수집하지 않습니다.

2.1 로컬 데이터

BambooNode로 생성하거나 가져온 모든 노트와 파일은 사용자 기기에 로컬로 저장됩니다. 이에는 다음이 포함됩니다:

  • 노트의 텍스트 내용
  • 노트에 추가한 이미지 및 첨부 파일
  • 파일 메타데이터(이름, 크기, 수정 날짜)
  • 노트를 구성하기 위한 태그 정보
  • 애플리케이션 설정 및 기본 설정

이 데이터는 사용자 기기의 저장 공간(다운로드 폴더 또는 다른 선택한 위치)에 저장되며, 우리 서버로 전송되지 않습니다.

2.2 선택적 Git 동기화 데이터

선택적 Git 동기화 기능을 활성화하면 사용자의 노트와 파일이 구성한 원격 Git 저장소에 업로드될 수 있습니다. 이는 사용자의 단독 재량에 따라 이루어지며 다음을 제공해야 합니다:

  • 원격 저장소 URL
  • 인증 자격 증명(사용자 이름/비밀번호 또는 액세스 토큰)

사용자의 Git 자격 증명은 Android의 안전한 기본 설정을 사용하여 기기에 로컬로 저장되며, 우리 서버로 전송되지 않습니다.

2.3 기기 정보(문제 해결용)

피드백 기능을 사용할 때 문제 해결을 위해 선택적으로 기기 정보를 제공할 수 있습니다. 이에는 다음이 포함될 수 있습니다:

  • Android 버전
  • 기기 모델
  • 애플리케이션 버전

이 정보는 사용자가 명시적으로 피드백을 제출할 때만 전송되며, 애플리케이션 개선에만 사용됩니다.

3. 어떻게 정보를 사용합니까?

사용자 정보는 다음 목적에만 사용됩니다:

  • BambooNode의 핵심 기능을 제공하고 유지하기 위해
  • 노트 및 파일의 로컬 저장 및 관리를 가능하게 하기 위해
  • 선택적 Git 동기화를 용이하게 하기 위해(활성화된 경우)
  • 피드백을 기반으로 애플리케이션을 개선하기 위해(제공된 경우)
  • 사용자 데이터의 안전성과 무결성을 보장하기 위해

4. 데이터 저장 및 보안

4.1 로컬 저장

사용자의 노트와 파일은 Android 기기에 로컬로 저장됩니다. 초기 설정 시 저장 위치(예: 다운로드 폴더)를 선택할 수 있습니다.

4.2 보안 조치

사용자 데이터를 보호하기 위해 다음을 포함한 합리적인 보안 조치를 시행합니다:

  • Android의 암호화된 기본 설정을 사용하여 Git 자격 증명을 안전하게 저장
  • 안전한 파일 관리를 위해 Android의 저장 액세스 프레임워크(SAF)를 사용하여 파일 작업 수행
  • 보안 취약점을 해결하기 위한 정기적인 업데이트

그러나 어떠한 저장 방법도 완전히 안전하지 않습니다. 사용자 데이터의 절대적인 안전을 보장할 수 없습니다.

5. 데이터 공유

우리는 어떠한 목적으로도 제3자에게 사용자의 개인정보를 공유, 판매 또는 대여하지 않습니다.

유일한 예외는 Git 동기화를 활성화한 경우로, 사용자 데이터가 지정한 원격 Git 저장소로 전송됩니다. 제3자 Git 제공업체가 사용자 데이터를 어떻게 처리하는지에 대한 제어권은 없습니다.

6. 권한

BambooNode는 기능을 수행하기 위해 다음 권한이 필요합니다:

  • INTERNET: Git 동기화 및 피드백 기능에 필요
  • READ_EXTERNAL_STORAGE: 기기에서 노트 및 파일을 읽기 위해 필요
  • WRITE_EXTERNAL_STORAGE: 기기에 노트 및 파일을 저장하기 위해 필요
  • MANAGE_EXTERNAL_STORAGE: Android 11+에서 외부 저장소에 대한 완전한 액세스에 필요

모든 권한은 실행 시 요청되며, 기기 설정을 통해 언제든지 취소할 수 있습니다. 하지만 특정 권한을 취소하면 애플리케이션의 기능에 영향을 줄 수 있습니다.

7. 사용자의 권리

사용자는 데이터에 대해 다음 권리를 가지고 있습니다:

  • 접근 권: 애플리케이션을 통해 모든 노트 및 파일에 직접 접근할 수 있습니다
  • 수정 권: 언제든지 노트 및 파일을 편집, 이름 변경 또는 삭제할 수 있습니다
  • 내보내기 권: 노트는 표준 Markdown(.md) 또는 텍스트(.txt) 파일로 저장되며, 어떠한 파일 관리자로도 내보낼 수 있습니다
  • 삭제 권: 애플리케이션을 제거하고 기기에서 파일을 삭제하여 모든 데이터를 삭제할 수 있습니다

8. EU 일반 데이터 보호 규정(GDPR) 준수 선언

BambooNode는 EU 일반 데이터 보호 규정(GDPR)을 준수하며, EU 및 유럽 경제 지역(EEA) 사용자의 개인 데이터 권리를 보호합니다.

8.1 데이터 관리자

BambooNode는 본 앱을 통해 처리되는 모든 개인 데이터의 데이터 관리자 역할을 합니다. 데이터 관리자는 사용자의 개인 데이터가 GDPR 규정에 따라 처리되도록 보장할 책임이 있습니다.

8.2 처리의 법적 근거

당사는 다음 법적 근거에 따라 사용자의 개인 데이터를 처리합니다:

  • 동의: 문제 해결을 위해 피드백 기능을 통해 명시적으로 기기 정보를 제공하는 경우
  • 계약 필요성: Git 동기화 기능을 사용할 때 요청하신 서비스를 제공하기 위해 필요한 데이터를 처리하는 경우
  • 정당한 이익: 애플리케이션 안정성과 사용자 경험을 개선하기 위해 익명 사용 데이터를 처리하는 경우

8.3 데이터 보유

사용자의 로컬 데이터(노트, 파일, 설정)는 사용자가 삭제를 선택하거나 애플리케이션을 제거할 때까지 기기에 보관됩니다. 피드백 데이터(있는 경우)는 보고된 문제를 해결하는 데 필요한 기간 동안만 보관되며, 그 이후에는 삭제됩니다.

8.4 국제 데이터 전송

Git 동기화 기능을 활성화하면, 사용자의 데이터가 EU/EEA 외부의 서버로 전송될 수 있습니다. 당사는 제3자 Git 제공업체의 데이터 처리 관행에 대해 책임지지 않습니다. 동기화를 활성화하기 전에 선택한 Git 제공업체의 개인정보 처리방침을 검토하시기 바랍니다.

8.5 EU/EEA 사용자의 추가 권리

제7장에 명시된 권리 외에도, EU/EEA 사용자는 GDPR에 따라 다음 권리를 가집니다:

  • 정정권: 부정확한 개인 데이터의 정정을 요청할 권리
  • 삭제권("잊혀질 권리"): 개인 데이터의 삭제를 요청할 권리
  • 처리 제한권: 개인 데이터의 처리 제한을 요청할 권리
  • 데이터 이동권: 개인 데이터를 구조화되고 기계 판독 가능한 형식으로 받을 권리
  • 반대권: 정당한 이익에 기반한 개인 데이터 처리에 반대할 권리
  • 동의 철회권: 언제든지 동의를 철회할 권리(철회 전 동의에 기반한 처리의 적법성에는 영향을 미치지 않습니다)

이러한 권리를 행사하려면 weijaky@gmail.com으로 연락해 주십시오. 당사는 GDPR 요구사항에 따라 30일 이내에 요청에 응답할 것입니다.

8.6 감독 기관

당사의 개인 데이터 처리가 GDPR을 침해한다고 판단되는 경우, 사용자는 소재지 또는 거주지의 감독 기관에 불만을 제기할 권리가 있습니다.

9. 개인정보 처리방침의 변경

우리는 개인정보 처리방침을 때때로 업데이트할 수 있습니다. 변경 사항이 있는 경우, 새 개인정보 처리방침을 이 페이지에 게시하고 "최종 업데이트" 날짜를 업데이트하여 알려드립니다.

본 방침의 변경 후에도 BambooNode를 계속 사용하는 것은 업데이트된 방침에 대한 동의를 의미합니다.
