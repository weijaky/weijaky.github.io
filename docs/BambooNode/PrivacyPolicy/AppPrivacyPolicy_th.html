นโยบายความเป็นส่วนตัวของ BambooNode

อัปเดตล่าสุด: 26 กรกฎาคม 2026

วันที่ใช้งาน: 26 กรกฎาคม 2026

1. บทนำ

BambooNode ("เรา" หรือ "แอปพลิเคชัน") เป็นแอปพลิเคชันบันทึกข้อความและจัดการไฟล์ที่พัฒนาสำหรับอุปกรณ์ Android นโยบายความเป็นส่วนตัวนี้อธิบายว่าเรารวบรวม ใช้ และปกป้องข้อมูลส่วนบุคคลของคุณเมื่อคุณใช้แอปพลิเคชันของเรา

เรามีความมุ่งมั่นที่จะปกป้องความเป็นส่วนตัวของคุณและรับประกันความปลอดภัยของข้อมูลของคุณ นโยบายนี้มีผลบังคับใช้กับผู้ใช้ทั้งหมดของ BambooNode

2. เรารวบรวมข้อมูลใดบ้าง?

BambooNode ถูกออกแบบมาเป็นแอปพลิเคชันที่เน้นความเป็นส่วนตัว เราไม่รวบรวมข้อมูลส่วนบุคคลใดๆ โดยไม่มีความรู้และความยินยอมชัดเจนจากคุณ

2.1 ข้อมูลท้องถิ่น

โน้ตและไฟล์ทั้งหมดที่คุณสร้างหรือนำเข้าโดยใช้ BambooNode จะถูกบันทึกไว้ในอุปกรณ์ของคุณ ขนาดนี้รวมถึง:

  • เนื้อหาข้อความของโน้ตของคุณ
  • รูปภาพและไฟล์แนบที่คุณเพิ่มลงในโน้ต
  • เมตาดาต้าไฟล์ (ชื่อ ขนาด วันที่แก้ไข)
  • ข้อมูลแท็กสำหรับการจัดระเบียบโน้ต
  • การตั้งค่าและการตั้งค่าโปรดของแอปพลิเคชัน

ข้อมูลนี้จะถูกบันทึกไว้ในพื้นที่เก็บข้อมูลของอุปกรณ์ของคุณ (โฟลเดอร์ดาวน์โหลดหรือตำแหน่งอื่นที่คุณเลือก) และจะไม่ถูกส่งไปยังเซิร์ฟเวอร์ของเรา

2.2 ข้อมูลการซิงโครไนซ์ Git ที่เลือกได้

หากคุณเปิดใช้งานฟังก์ชันการซิงโครไนซ์ Git ที่เลือกได้ โน้ตและไฟล์ของคุณอาจจะถูกอัปโหลดไปยังที่เก็บ Git ทางไกลที่คุณตั้งค่า นี่เป็นการตัดสินใจโดยคุณเองและต้องให้:

  • URL ของที่เก็บทางไกล
  • ข้อมูลรับรองการยืนยันตัวตน (ชื่อผู้ใช้/รหัสผ่านหรือโทเค็นการเข้าถึง)

ข้อมูลรับรองการยืนยันตัวตน Git ของคุณจะถูกบันทึกไว้ในอุปกรณ์ของคุณโดยใช้การตั้งค่าที่ปลอดภัยของ Android และจะไม่ถูกส่งไปยังเซิร์ฟเวอร์ของเรา

2.3 ข้อมูลอุปกรณ์ (สำหรับการแก้ปัญหา)

เมื่อคุณใช้ฟังก์ชันคำติชม คุณสามารถให้ข้อมูลอุปกรณ์ได้ตามต้องการเพื่อช่วยเราจัดการปัญหา สิ่งนี้อาจรวมถึง:

  • เวอร์ชัน Android
  • รุ่นอุปกรณ์
  • เวอร์ชันแอปพลิเคชัน

ข้อมูลนี้จะถูกส่งเฉพาะเมื่อคุณส่งคำติชมอย่างชัดเจนและจะใช้เพียงเพื่อปรับปรุงแอปพลิเคชันเท่านั้น

3. เราใช้ข้อมูลของคุณอย่างไร?

เราใช้ข้อมูลของคุณเพื่อวัตถุประสงค์ต่อไปนี้เท่านั้น:

  • เพื่อให้บริการและรักษาฟังก์ชันหลักของ BambooNode
  • เพื่อเปิดใช้งานการเก็บข้อมูลท้องถิ่นและการจัดการโน้ตและไฟล์ของคุณ
  • เพื่อให้การซิงโครไนซ์ Git ที่เลือกได้เป็นไปได้ (หากเปิดใช้งาน)
  • เพื่อปรับปรุงแอปพลิเคชันตามคำติชม (หากให้)
  • เพื่อรับประกันความปลอดภัยและความสมบูรณ์ของข้อมูลของคุณ

4. การเก็บข้อมูลและความปลอดภัย

4.1 การเก็บข้อมูลท้องถิ่น

โน้ตและไฟล์ของคุณจะถูกบันทึกไว้ในอุปกรณ์ Android ของคุณ คุณสามารถเลือกตำแหน่งเก็บข้อมูล (เช่น โฟลเดอร์ดาวน์โหลด) ระหว่างการตั้งค่าเริ่มต้น

4.2 การป้องกัน

เราทำการป้องกันที่สมเหตุสมผลเพื่อปกป้องข้อมูลของคุณ รวมถึง:

  • การเก็บข้อมูลรับรองการยืนยันตัวตน Git ที่ปลอดภัยโดยใช้การตั้งค่าที่เข้ารหัสของ Android
  • การดำเนินการไฟล์โดยใช้กรอบการเข้าถึงการเก็บข้อมูล (SAF) ของ Android สำหรับการจัดการไฟล์ที่ปลอดภัย
  • การอัปเดตเป็นประจำเพื่อแก้ไขช่องโหว่ความปลอดภัย

อย่างไรก็ตาม ไม่มีวิธีการเก็บข้อมูลที่ปลอดภัยอย่างสมบูรณ์ เราไม่สามารถรับประกันความปลอดภัยอย่างสมบูรณ์ของข้อมูลของคุณ

5. การแบ่งปันข้อมูล

เราไม่แบ่งปัน ขาย หรือเช่า ข้อมูลส่วนบุคคลของคุณให้กับบุคคลที่สามเพื่อวัตถุประสงค์ใดๆ

ข้อยกเว้นเดียวคือเมื่อคุณเปิดใช้งานการซิงโครไนซ์ Git ซึ่งข้อมูลของคุณจะถูกส่งไปยังที่เก็บ Git ทางไกลที่คุณระบุ เราไม่มีการควบคุมว่าผู้ให้บริการ Git ของบุคคลที่สามจัดการข้อมูลของคุณอย่างไร

6. สิทธิ์

BambooNode ต้องมีสิทธิ์ต่อไปนี้เพื่อทำงาน:

  • INTERNET: จำเป็นสำหรับการซิงโครไนซ์ Git และฟังก์ชันคำติชม
  • READ_EXTERNAL_STORAGE: จำเป็นสำหรับการอ่านโน้ตและไฟล์จากอุปกรณ์ของคุณ
  • WRITE_EXTERNAL_STORAGE: จำเป็นสำหรับการบันทึกโน้ตและไฟล์ลงอุปกรณ์ของคุณ
  • MANAGE_EXTERNAL_STORAGE: จำเป็นสำหรับการเข้าถึงการเก็บข้อมูลภายนอกอย่างเต็มที่บน Android 11+

สิทธิ์ทั้งหมดจะถูกขอในระหว่างการรัน และคุณสามารถยกเลิกได้ตลอดเวลาผ่านการตั้งค่าอุปกรณ์ ของคุณ อย่างไรก็ตาม การยกเลิกสิทธิ์บางรายการอาจส่งผลกระทบต่อการทำงานของแอปพลิเคชัน

7. สิทธิ์ของคุณ

คุณมีสิทธิ์ต่อไปนี้เกี่ยวกับข้อมูลของคุณ:

  • การเข้าถึง: คุณสามารถเข้าถึงโน้ตและไฟล์ทั้งหมดของคุณโดยตรงผ่านแอปพลิเคชัน
  • การแก้ไข: คุณสามารถแก้ไข เปลี่ยนชื่อ หรือลบโน้ตและไฟล์ของคุณได้ตลอดเวลา
  • การส่งออก: โน้ตของคุณจะถูกบันทึกเป็นไฟล์ Markdown (.md) หรือข้อความ (.txt) มาตรฐาน ซึ่งคุณสามารถส่งออกโดยใช้โปรแกรมจัดการไฟล์ใดๆ
  • การลบ: คุณสามารถลบข้อมูลทั้งหมดของคุณได้โดยการถอนการติดตั้งแอปพลิเคชันและลบไฟล์จากอุปกรณ์ของคุณ

8. การปฏิบัติตามข้อบังคับทั่วไปเกี่ยวกับการคุ้มครองข้อมูลของสหภาพยุโรป (GDPR)

BambooNode ปฏิบัติตามข้อบังคับทั่วไปเกี่ยวกับการคุ้มครองข้อมูลของสหภาพยุโรป (GDPR) สำหรับผู้ใช้ภายในสหภาพยุโรปและเขตเศรษฐกิจยุโรป (EEA)

8.1 ผู้ควบคุมข้อมูล

BambooNode ทำหน้าที่เป็นผู้ควบคุมข้อมูลสำหรับข้อมูลส่วนบุคคลใดๆ ที่ประมวลผลผ่านแอปพลิเคชัน ผู้ควบคุมข้อมูลมีหน้าที่รับผิดชอบในการรับประกันว่าข้อมูลส่วนบุคคลของคุณได้รับการประมวลผลตาม GDPR

8.2 ฐานทางกฎหมายสำหรับการประมวลผล

เราประมวลผลข้อมูลส่วนบุคคลของคุณโดยอิงตามฐานทางกฎหมายดังต่อไปนี้:

  • ความยินยอม: เมื่อคุณให้ข้อมูลอุปกรณ์อย่างชัดเจนเพื่อการแก้ไขปัญหาผ่านฟังก์ชันคำติชม
  • ความจำเป็นตามสัญญา: เมื่อคุณใช้การซิงโครไนซ์ Git เราประมวลผลข้อมูลที่จำเป็นเพื่อให้บริการที่คุณร้องขอ
  • ผลประโยชน์ที่ชอบด้วยกฎหมาย: เราอาจประมวลผลข้อมูลการใช้งานที่ไม่ระบุตัวตนเพื่อปรับปรุงความเสถียรของแอปพลิเคชันและประสบการณ์ผู้ใช้

8.3 การเก็บรักษาข้อมูล

ข้อมูลท้องถิ่นของคุณ (โน้ต ไฟล์ การตั้งค่า) จะถูกเก็บไว้ในอุปกรณ์ของคุณจนกว่าคุณจะเลือกลบหรือถอนการติดตั้งแอปพลิเคชัน ข้อมูลคำติชม หากได้รับการให้ จะถูกเก็บไว้เพียงเท่าที่จำเป็นเพื่อแก้ไขปัญหาที่รายงานและจะถูกลบหลังจากนั้น

8.4 การโอนข้อมูลระหว่างประเทศ

หากคุณเปิดใช้งานการซิงโครไนซ์ Git ข้อมูลของคุณอาจถูกโอนไปยังเซิร์ฟเวอร์ที่ตั้งอยู่นอก EU/EEA เราไม่รับผิดชอบต่อแนวปฏิบัติในการจัดการข้อมูลของผู้ให้บริการ Git ของบุคคลที่สาม โปรดตรวจสอบนโยบายความเป็นส่วนตัวของผู้ให้บริการ Git ที่คุณเลือกก่อนเปิดใช้งานการซิงโครไนซ์

8.5 สิทธิเพิ่มเติมของผู้ใช้ EU/EEA

นอกเหนือจากสิทธิที่ระบุในส่วนที่ 7 ผู้ใช้ EU/EEA มีสิทธิดังต่อไปนี้ภายใต้ GDPR:

  • สิทธิในการแก้ไข: คุณสามารถร้องขอการแก้ไขข้อมูลส่วนบุคคลที่ไม่ถูกต้องได้
  • สิทธิในการลบ ("สิทธิในการถูกลืม"): คุณสามารถร้องขอการลบข้อมูลส่วนบุคคลของคุณได้
  • สิทธิในการจำกัดการประมวลผล: คุณสามารถร้องขอให้เราจำกัดการประมวลผลข้อมูลส่วนบุคคลของคุณได้
  • สิทธิในการโอนย้ายข้อมูล: คุณสามารถรับข้อมูลส่วนบุคคลของคุณในรูปแบบที่มีโครงสร้างและอ่านได้ด้วยเครื่องได้
  • สิทธิในการคัดค้าน: คุณสามารถคัดค้านการประมวลผลข้อมูลส่วนบุคคลของคุณที่อิงตามผลประโยชน์ที่ชอบด้วยกฎหมายได้
  • สิทธิในการถอนความยินยอม: คุณสามารถถอนความยินยอมของคุณได้ตลอดเวลาโดยไม่กระทบต่อความชอบด้วยกฎหมายของการประมวลผลที่อิงตามความยินยอมก่อนการถอน

8.6 หน่วยงานกำกับดูแล

หากคุณเชื่อว่าการประมวลผลข้อมูลส่วนบุคคลของคุณโดยเราละเมิด GDPR คุณมีสิทธิที่จะยื่นร้องเรียนต่อหน่วยงานกำกับดูแลในท้องถิ่นของคุณหรือหน่วยงานกำกับดูแลในที่ที่คุณอาศัยอยู่

9. การเปลี่ยนแปลงนโยบายความเป็นส่วนตัวนี้

เราอาจจะอัปเดตนโยบายความเป็นส่วนตัวนี้เป็นระยะๆ เราจะแจ้งให้คุณทราบเกี่ยวกับการเปลี่ยนแปลงใดๆ โดยการเผยแพร่นโยบายความเป็นส่วนตัวใหม่บนหน้านี้และอัปเดตวันที่ "อัปเดตล่าสุด"

การใช้งาน BambooNode อย่างต่อเนื่องหลังจากการเปลี่ยนแปลงใดๆ ในนโยบายนี้จะถือว่าเป็นการยอมรับนโยบายที่อัปเดต
