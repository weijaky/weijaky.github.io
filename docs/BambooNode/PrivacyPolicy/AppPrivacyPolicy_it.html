Informativa sulla privacy di BambooNode

Ultimo aggiornamento: 26 luglio 2026

Data di entrata in vigore: 26 luglio 2026

1. Introduzione

BambooNode ("noi", "nostro" o "l'applicazione") è un'applicazione per la gestione di note e file sviluppata per dispositivi Android. Questa informativa sulla privacy spiega come raccogliamo, utilizziamo e proteggiamo le tue informazioni personali quando usi la nostra applicazione.

Siamo impegnati a proteggere la tua privacy e a garantire la sicurezza dei tuoi dati. Questa politica si applica a tutti gli utenti di BambooNode.

2. Quali informazioni raccogliamo?

BambooNode è progettata come un'applicazione orientata alla privacy. Non raccogliamo alcuna informazione personale senza la tua conoscenza e consenso espliciti.

2.1 Dati locali

Tutte le note e i file che crei o importi con BambooNode vengono memorizzati localmente sul tuo dispositivo. Questo include:

  • Contenuto testuale delle tue note
  • Immagini e allegati che aggiungi alle note
  • Metadati dei file (nomi, dimensioni, date di modifica)
  • Informazioni sui tag per organizzare le note
  • Impostazioni e preferenze dell'applicazione

Questi dati sono memorizzati nello spazio di archiviazione del tuo dispositivo (cartella Download o altra posizione selezionata) e non vengono mai trasmessi ai nostri server.

2.2 Dati opzionali di sincronizzazione Git

Se attivi la funzione opzionale di sincronizzazione Git, le tue note e i tuoi file potrebbero essere caricati in un repository Git remoto che configuri. Questo avviene a tua sola discrezione e richiede che tu fornisca:

  • URL del repository remoto
  • Credenziali di autenticazione (nome utente/password o token di accesso)

Le tue credenziali Git sono memorizzate localmente sul tuo dispositivo utilizzando le preferenze sicure di Android e non vengono mai trasmesse ai nostri server.

2.3 Informazioni sul dispositivo (per il risoluzione dei problemi)

Quando usi la funzione di feedback, puoi fornire opzionalmente informazioni sul dispositivo per aiutarci a risolvere i problemi. Questo può includere:

  • Versione di Android
  • Modello del dispositivo
  • Versione dell'applicazione

Queste informazioni vengono inviate solo quando invii esplicitamente un feedback e vengono utilizzate esclusivamente per migliorare l'applicazione.

3. Come utilizziamo le tue informazioni?

Utilizziamo le tue informazioni solo per i seguenti scopi:

  • Fornire e mantenere la funzionalità core di BambooNode
  • Abilitare l'archiviazione locale e la gestione delle tue note e file
  • Facilitare la sincronizzazione Git opzionale (se attivata)
  • Migliorare l'applicazione in base ai feedback (se forniti)
  • Garantire la sicurezza e l'integrità dei tuoi dati

4. Archiviazione e sicurezza dei dati

4.1 Archiviazione locale

Le tue note e i tuoi file sono memorizzati localmente sul tuo dispositivo Android. Puoi scegliere la posizione di archiviazione (es. cartella Download) durante la configurazione iniziale.

4.2 Misure di sicurezza

Implementiamo misure di sicurezza ragionevoli per proteggere i tuoi dati, tra cui:

  • Archiviazione sicura delle credenziali Git utilizzando le preferenze criptate di Android
  • Operazioni sui file utilizzando il Framework di Accesso all'Archiviazione (SAF) di Android per una gestione sicura dei file
  • Aggiornamenti regolari per affrontare le vulnerabilità di sicurezza

Tuttavia, nessun metodo di archiviazione è completamente sicuro. Non possiamo garantire la sicurezza assoluta dei tuoi dati.

5. Condivisione dei dati

Non condividiamo, vendiamo o affittiamo le tue informazioni personali a terzi per alcun motivo.

L'unica eccezione è quando attivi la sincronizzazione Git, nel qual caso i tuoi dati vengono trasmessi al repository Git remoto che specifichi. Non abbiamo controllo su come i provider Git di terzi gestiscono i tuoi dati.

6. Permessi

BambooNode richiede i seguenti permessi per funzionare:

  • INTERNET: Richiesto per la sincronizzazione Git e le funzionalità di feedback
  • READ_EXTERNAL_STORAGE: Richiesto per leggere note e file dal tuo dispositivo
  • WRITE_EXTERNAL_STORAGE: Richiesto per salvare note e file sul tuo dispositivo
  • MANAGE_EXTERNAL_STORAGE: Richiesto per l'accesso completo all'archiviazione esterna su Android 11+

Tutti i permessi vengono richiesti in fase di esecuzione e puoi revocarli in qualsiasi momento tramite le impostazioni del tuo dispositivo. Tuttavia, la revoca di alcuni permessi potrebbe influire sulla funzionalità dell'applicazione.

7. I tuoi diritti

Hai i seguenti diritti riguardanti i tuoi dati:

  • Accesso: Puoi accedere a tutte le tue note e file direttamente attraverso l'applicazione
  • Modifica: Puoi modificare, rinominare o eliminare le tue note e file in qualsiasi momento
  • Esportazione: Le tue note sono memorizzate come file Markdown (.md) o testo (.txt) standard, che puoi esportare utilizzando qualsiasi gestore di file
  • Cancellazione: Puoi cancellare tutti i tuoi dati disinstallando l'applicazione e rimuovendo i file dal tuo dispositivo

8. Conformità al Regolamento Generale sulla Protezione dei Dati (GDPR) dell'UE

BambooNode è conforme al Regolamento Generale sulla Protezione dei Dati (GDPR) dell'UE per gli utenti all'interno dell'Unione Europea e dello Spazio Economico Europeo (SEE).

8.1 Titolare del trattamento

BambooNode agisce come titolare del trattamento per qualsiasi dato personale trattato tramite l'applicazione. Il titolare del trattamento è responsabile di garantire che i tuoi dati personali siano trattati in conformità con il GDPR.

8.2 Base giuridica del trattamento

Trattiamo i tuoi dati personali sulla base dei seguenti fondamenti giuridici:

  • Consenso: Quando fornisci esplicitamente informazioni sul dispositivo per la risoluzione dei problemi tramite la funzione di feedback
  • Necessità contrattuale: Quando utilizzi la sincronizzazione Git, trattiamo i dati necessari per fornire il servizio da te richiesto
  • Interessi legittimi: Possiamo trattare dati di utilizzo anonimi per migliorare la stabilità dell'applicazione e l'esperienza dell'utente

8.3 Conservazione dei dati

I tuoi dati locali (note, file, impostazioni) sono conservati sul tuo dispositivo finché non scegli di eliminarli o di disinstallare l'applicazione. I dati di feedback, se forniti, sono conservati solo per il tempo necessario a risolvere il problema segnalato e poi eliminati.

8.4 Trasferimenti internazionali di dati

Se attivi la sincronizzazione Git, i tuoi dati possono essere trasferiti a server situati al di fuori dell'UE/SEE. Non siamo responsabili delle pratiche di gestione dei dati dei provider Git di terze parti. Ti invitiamo a consultare l'informativa sulla privacy del provider Git scelto prima di attivare la sincronizzazione.

8.5 Diritti aggiuntivi degli utenti UE/SEE

Oltre ai diritti elencati nella Sezione 7, gli utenti UE/SEE hanno i seguenti diritti ai sensi del GDPR:

  • Diritto di rettifica: Puoi richiedere la correzione di dati personali inesatti
  • Diritto alla cancellazione ("Diritto all'oblio"): Puoi richiedere la cancellazione dei tuoi dati personali
  • Diritto di limitazione del trattamento: Puoi richiedere che limitiamo il trattamento dei tuoi dati personali
  • Diritto alla portabilità dei dati: Puoi ricevere i tuoi dati personali in un formato strutturato, di uso comune e leggibile da macchina
  • Diritto di opposizione: Puoi opporti al trattamento dei tuoi dati personali basato su interessi legittimi
  • Diritto di revoca del consenso: Puoi revocare il tuo consenso in qualsiasi momento senza pregiudicare la liceità del trattamento basato sul consenso prima della sua revoca

Per esercitare questi diritti, contattaci all'indirizzo weijaky@gmail.com. Risponderemo alla tua richiesta entro 30 giorni come richiesto dal GDPR.

8.6 Autorità di controllo

Se ritieni che il nostro trattamento dei tuoi dati personali violi il GDPR, hai il diritto di presentare un reclamo alla tua autorità di controllo locale o all'autorità di controllo del luogo in cui risiedi.
