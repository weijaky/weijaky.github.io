Политика конфиденциальности BambooNode

Последнее обновление: 26 июля 2026 г.

Дата вступления в силу: 26 июля 2026 г.

1. Введение

BambooNode ("мы", "наш" или "наше") — это приложение для создания заметок и управления файлами, разработанное для устройств Android. Настоящая Политика конфиденциальности объясняет, как мы собираем, используем и защищаем ваши персональные данные при использовании нашего приложения.

Мы стремимся защищать вашу конфиденциальность и обеспечивать безопасность ваших данных. Настоящая политика распространяется на всех пользователей BambooNode.

2. Какие данные мы собираем?

BambooNode разработано как приложение, ориентированное на защиту конфиденциальности. Мы не собираем персональные данные без вашего явного согласия.

2.1 Локальные данные

Все заметки и файлы, которые вы создаете или импортируете с помощью BambooNode, хранятся локально на вашем устройстве. Это включает:

  • Текстовое содержимое ваших заметок
  • Изображения и вложения, добавляемые в заметки
  • Метаданные файлов (названия, размеры, даты изменения)
  • Информация о тегах для организации заметок
  • Настройки и предпочтения приложения

Эти данные хранятся в памяти вашего устройства (папка Downloads или другой выбранный каталог) и никогда не передаются на наши сервера.

2.2 Необязательные данные синхронизации Git

Если вы включите необязательную функцию синхронизации Git, ваши заметки и файлы могут быть загружены в удаленный репозиторий Git, который вы настроите. Это делается по вашему усмотрению и требует предоставления:

  • URL удаленного репозитория
  • Учетные данные для аутентификации (имя пользователя/пароль или токен доступа)

Ваши учетные данные Git хранятся локально на вашем устройстве с использованием безопасных настроек Android и никогда не передаются на наши сервера.

2.3 Информация о устройстве (для устранения неполадок)

При использовании функции обратной связи вы можете предоставить информацию о устройстве для помощи в устранении неполадок. Это может включать:

  • Версию Android
  • Модель устройства
  • Версию приложения

Эта информация отправляется только при явном отправке обратной связи и используется исключительно для улучшения приложения.

3. Как мы используем ваши данные?

Мы используем ваши данные только для следующих целей:

  • Предоставление и поддержка основных функций BambooNode
  • Включение локального хранения и управления вашими заметками и файлами
  • Обеспечение необязательной синхронизации Git (если включена)
  • Улучшение приложения на основе обратной связи (если предоставлена)
  • Обеспечение безопасности и целостности ваших данных

4. Хранение и безопасность данных

4.1 Локальное хранение

Ваши заметки и файлы хранятся локально на вашем устройстве Android. При первоначальной настройке вы можете выбрать место хранения (например, папку Downloads).

4.2 Меры безопасности

Мы применяем разумные меры безопасности для защиты ваших данных, включая:

  • Безопасное хранение учетных данных Git с использованием зашифрованных настроек Android
  • Операции с файлами с использованием Фреймворка доступа к хранилищу Android (SAF) для безопасного управления файлами
  • Регулярные обновления для исправления уязвимостей безопасности

Однако ни один метод хранения не является абсолютно безопасным. Мы не можем гарантировать абсолютную безопасность ваших данных.

5. Обмен данными

Мы не передаем, не продаем и не сдаем в аренду ваши персональные данные третьим лицам.

Единственное исключение — включение синхронизации Git, при этом ваши данные передаются в указанный удаленный репозиторий Git. Мы не контролируем, как третьи поставщики Git обрабатывают ваши данные.

6. Разрешения

BambooNode требует следующих разрешений для работы:

  • INTERNET: Необходимо для синхронизации Git и функций обратной связи
  • READ_EXTERNAL_STORAGE: Необходимо для чтения заметок и файлов с вашего устройства
  • WRITE_EXTERNAL_STORAGE: Необходимо для сохранения заметок и файлов на вашем устройстве
  • MANAGE_EXTERNAL_STORAGE: Необходимо для полного доступа к внешнему хранилищу в Android 11+

Все разрешения запрашиваются во время выполнения, и вы можете отозвать их в любое время через настройки устройства. Однако отозвание некоторых разрешений может повлиять на функциональность приложения.

7. Ваши права

Вы имеете следующие права в отношении своих данных:

  • Доступ: Вы можете напрямую получить доступ ко всем своим заметкам и файлам через приложение
  • Изменение: Вы можете в любое время редактировать, переименовывать или удалять свои заметки и файлы
  • Экспорт: Ваши заметки хранятся в виде стандартных файлов Markdown (.md) или текста (.txt), которые вы можете экспортировать с помощью любого файлового менеджера
  • Удаление: Вы можете удалить все свои данные, удалив приложение и файлы с устройства

8. Соответствие Общему регламенту по защите данных ЕС (GDPR)

BambooNode соответствует Общему регламенту по защите данных Европейского Союза (GDPR) для пользователей в Европейском Союзе и Европейской экономической зоне (ЕЭЗ).

8.1 Контролер данных

BambooNode выступает в качестве контролера данных для любых персональных данных, обрабатываемых через приложение. Контролер данных несет ответственность за обеспечение обработки ваших персональных данных в соответствии с GDPR.

8.2 Правовое основание для обработки

Мы обрабатываем ваши персональные данные на следующих правовых основаниях:

  • Согласие: Когда вы явно предоставляете информацию об устройстве для устранения неполадок через функцию обратной связи
  • Договорная необходимость: Когда вы используете синхронизацию Git, мы обрабатываем необходимые данные для предоставления запрошенной вами услуги
  • Законные интересы: Мы можем обрабатывать анонимные данные об использовании для повышения стабильности приложения и удобства пользователей

8.3 Хранение данных

Ваши локальные данные (заметки, файлы, настройки) хранятся на вашем устройстве до тех пор, пока вы не решите их удалить или не удалите приложение. Данные обратной связи, если они предоставлены, хранятся только в течение времени, необходимого для решения заявленной проблемы, а затем удаляются.

8.4 Международная передача данных

Если вы включите синхронизацию Git, ваши данные могут быть переданы на серверы, расположенные за пределами ЕС/ЕЭЗ. Мы не несем ответственности за практики обработки данных сторонних поставщиков Git. Ознакомьтесь с политикой конфиденциальности выбранного вами поставщика Git перед включением синхронизации.

8.5 Дополнительные права пользователей ЕС/ЕЭЗ

В дополнение к правам, перечисленным в Разделе 7, пользователи ЕС/ЕЭЗ имеют следующие права в соответствии с GDPR:

  • Право на исправление: Вы можете запросить исправление неточных персональных данных
  • Право на удаление ("право быть забытым"): Вы можете запросить удаление ваших персональных данных
  • Право на ограничение обработки: Вы можете попросить нас ограничить обработку ваших персональных данных
  • Право на переносимость данных: Вы можете получить свои персональные данные в структурированном, машиночитаемом формате
  • Право на возражение: Вы можете возражать против обработки ваших персональных данных на основе законных интересов
  • Право на отзыв согласия: Вы можете отозвать свое согласие в любое время без влияния на законность обработки, основанной на согласии до его отзыва

Для реализации этих прав свяжитесь с нами по адресу weijaky@gmail.com. Мы ответим на ваш запрос в течение 30 дней, как того требует GDPR.

8.6 Надзорный орган

Если вы считаете, что наша обработка ваших персональных данных нарушает GDPR, вы имеете право подать жалобу в местный надзорный орган или в надзорный орган по месту вашего жительства.

9. Изменения в Политике конфиденциальности

Мы можем время от времени обновлять Политику конфиденциальности. Изменения будут сообщать путем публикации новой Политики конфиденциальности на этой странице и обновления даты "Последнее обновление".

Продолжение использования BambooNode после изменений в Политике означает ваше согласие с обновленной Политикой.
