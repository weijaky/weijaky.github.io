Kebijakan Privasi BambooNode

Tanggal Pembaruan Terakhir: 26 Juli 2026

Tanggal Berlaku: 26 Juli 2026

1. Pendahuluan

BambooNode ("kami", "kami", atau "aplikasi") adalah aplikasi catatan dan manajemen file yang dikembangkan untuk perangkat Android. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi pribadi Anda saat Anda menggunakan aplikasi kami.

Kami berkomitmen untuk melindungi privasi Anda dan memastikan keamanan data Anda. Kebijakan ini berlaku untuk semua pengguna BambooNode.

2. Informasi Apa yang Kami Kumpulkan?

BambooNode dirancang sebagai aplikasi yang berfokus pada privasi. Kami tidak mengumpulkan informasi pribadi apa pun tanpa pengetahuan dan persetujuan eksplisit Anda.

2.1 Data Lokal

Semua catatan dan file yang Anda buat atau impor menggunakan BambooNode disimpan secara lokal di perangkat Anda. Ini termasuk:

  • Konten teks catatan Anda
  • Gambar dan lampiran yang Anda tambahkan ke catatan
  • Metadata file (nama, ukuran, tanggal modifikasi)
  • Informasi tag untuk mengatur catatan
  • Pengaturan dan preferensi aplikasi

Data ini disimpan di penyimpanan perangkat Anda (folder Unduhan atau lokasi lain yang dipilih) dan tidak pernah dikirim ke server kami.

2.2 Data Sinkronisasi Git Opsional

Jika Anda mengaktifkan fitur sinkronisasi Git opsional, catatan dan file Anda mungkin diunggah ke repositori Git jarak jauh yang Anda konfigurasikan. Ini dilakukan atas kebijaksanaan Anda sendiri dan membutuhkan Anda untuk memberikan:

  • URL repositori jarak jauh
  • Kredensial autentikasi (nama pengguna/kata sandi atau token akses)

Kredensial Git Anda disimpan secara lokal di perangkat Anda menggunakan preferensi aman Android dan tidak pernah dikirim ke server kami.

2.3 Informasi Perangkat (Untuk Memecahkan Masalah)

Saat Anda menggunakan fitur umpan balik, Anda dapat secara opsional memberikan informasi perangkat untuk membantu kami memecahkan masalah. Ini mungkin termasuk:

  • Versi Android
  • Model perangkat
  • Versi aplikasi

Informasi ini hanya dikirim ketika Anda secara eksplisit mengirim umpan balik dan hanya digunakan untuk meningkatkan aplikasi.

3. Bagaimana Kami Menggunakan Informasi Anda?

Kami hanya menggunakan informasi Anda untuk tujuan berikut:

  • Untuk menyediakan dan memelihara fungsi inti BambooNode
  • Untuk memungkinkan penyimpanan lokal dan manajemen catatan dan file Anda
  • Untuk memfasilitasi sinkronisasi Git opsional (jika diaktifkan)
  • Untuk meningkatkan aplikasi berdasarkan umpan balik (jika diberikan)
  • Untuk memastikan keamanan dan integritas data Anda

4. Penyimpanan dan Keamanan Data

4.1 Penyimpanan Lokal

Catatan dan file Anda disimpan secara lokal di perangkat Android Anda. Anda dapat memilih lokasi penyimpanan (misalnya, folder Unduhan) selama pengaturan awal.

4.2 Langkah Keamanan

Kami menerapkan langkah keamanan yang wajar untuk melindungi data Anda, termasuk:

  • Penyimpanan aman kredensial Git menggunakan preferensi terenkripsi Android
  • Operasi file menggunakan Kerangka Akses Penyimpanan (SAF) Android untuk manajemen file yang aman
  • Pembaruan reguler untuk mengatasi kerentanan keamanan

Namun, tidak ada metode penyimpanan yang sepenuhnya aman. Kami tidak dapat menjamin keamanan mutlak data Anda.

5. Pembagian Data

Kami tidak membagikan, menjual, atau menyewakan informasi pribadi Anda ke pihak ketiga untuk tujuan apa pun.

Pengecualian satu-satunya adalah ketika Anda mengaktifkan sinkronisasi Git, di mana data Anda dikirim ke repositori Git jarak jauh yang Anda tentukan. Kami tidak memiliki kontrol atas bagaimana penyedia Git pihak ketiga menangani data Anda.

6. Izin

BambooNode memerlukan izin berikut untuk berfungsi:

  • INTERNET: Diperlukan untuk sinkronisasi Git dan fitur umpan balik
  • READ_EXTERNAL_STORAGE: Diperlukan untuk membaca catatan dan file dari perangkat Anda
  • WRITE_EXTERNAL_STORAGE: Diperlukan untuk menyimpan catatan dan file ke perangkat Anda
  • MANAGE_EXTERNAL_STORAGE: Diperlukan untuk akses penuh ke penyimpanan eksternal pada Android 11+

Semua izin diminta saat runtime, dan Anda dapat mencabutnya kapan pun melalui pengaturan perangkat Anda. Namun, pencabutan beberapa izin dapat mempengaruhi fungsionalitas aplikasi.

7. Hak Anda

Anda memiliki hak berikut mengenai data Anda:

  • Akses: Anda dapat mengakses semua catatan dan file Anda langsung melalui aplikasi
  • Modifikasi: Anda dapat mengedit, mengganti nama, atau menghapus catatan dan file Anda kapan pun
  • Ekspor: Catatan Anda disimpan sebagai file Markdown (.md) atau teks (.txt) standar, yang dapat Anda ekspor menggunakan manajer file apa pun
  • Penghapusan: Anda dapat menghapus semua data Anda dengan menghapus aplikasi dan menghapus file dari perangkat Anda

8. Kepatuhan terhadap Peraturan Perlindungan Data Umum Uni Eropa (GDPR)

BambooNode mematuhi Peraturan Perlindungan Data Umum Uni Eropa (GDPR) bagi pengguna di dalam Uni Eropa dan Wilayah Ekonomi Eropa (EEA).

8.1 Pengendali Data

BambooNode bertindak sebagai pengendali data untuk setiap data pribadi yang diproses melalui aplikasi. Pengendali data bertanggung jawab untuk memastikan bahwa data pribadi Anda diproses sesuai dengan GDPR.

8.2 Dasar Hukum untuk Pemrosesan

Kami memproses data pribadi Anda berdasarkan dasar hukum berikut:

  • Persetujuan: Ketika Anda secara eksplisit memberikan informasi perangkat untuk pemecahan masalah melalui fitur umpan balik
  • Kebutuhan Kontraktual: Ketika Anda menggunakan sinkronisasi Git, kami memproses data yang diperlukan untuk memberikan layanan yang Anda minta
  • Kepentingan yang Sah: Kami mungkin memproses data penggunaan anonim untuk meningkatkan stabilitas aplikasi dan pengalaman pengguna

8.3 Penyimpanan Data

Data lokal Anda (catatan, file, pengaturan) disimpan di perangkat Anda hingga Anda memilih untuk menghapusnya atau menghapus instalasi aplikasi. Data umpan balik, jika diberikan, disimpan hanya selama waktu yang diperlukan untuk menyelesaikan masalah yang dilaporkan dan kemudian dihapus.

8.4 Transfer Data Internasional

Jika Anda mengaktifkan sinkronisasi Git, data Anda mungkin ditransfer ke server yang berlokasi di luar UE/EEA. Kami tidak bertanggung jawab atas praktik penanganan data oleh penyedia Git pihak ketiga. Harap tinjau kebijakan privasi penyedia Git pilihan Anda sebelum mengaktifkan sinkronisasi.

8.5 Hak Tambahan Pengguna UE/EEA

Selain hak-hak yang tercantum di Bagian 7, pengguna UE/EEA memiliki hak berikut berdasarkan GDPR:

  • Hak untuk Koreksi: Anda dapat meminta koreksi data pribadi yang tidak akurat
  • Hak untuk Penghapusan ("Hak untuk Dilupakan"): Anda dapat meminta penghapusan data pribadi Anda
  • Hak untuk Pembatasan Pemrosesan: Anda dapat meminta kami untuk membatasi pemrosesan data pribadi Anda
  • Hak Portabilitas Data: Anda dapat menerima data pribadi Anda dalam format yang terstruktur dan dapat dibaca mesin
  • Hak untuk Keberatan: Anda dapat keberatan terhadap pemrosesan data pribadi Anda berdasarkan kepentingan yang sah
  • Hak untuk Menarik Persetujuan: Anda dapat menarik persetujuan Anda kapan saja tanpa memengaruhi sahnya pemrosesan berdasarkan persetujuan sebelum penarikan

Untuk menggunakan hak-hak ini, silakan hubungi kami di weijaky@gmail.com. Kami akan menanggapi permintaan Anda dalam 30 hari sebagaimana diwajibkan oleh GDPR.

8.6 Otoritas Pengawas

Jika Anda yakin bahwa pemrosesan data pribadi Anda oleh kami melanggar GDPR, Anda berhak mengajukan keluhan kepada otoritas pengawas lokal Anda atau kepada otoritas pengawas di negara tempat Anda tinggal.

9. Perubahan pada Kebijakan Privasi Ini

Kami mungkin memperbarui Kebijakan Privasi ini dari waktu ke waktu. Kami akan memberi tahu Anda tentang perubahan dengan memposting Kebijakan Privasi baru di halaman ini dan memperbarui tanggal "Pembaruan Terakhir".

Penggunaan terus-menerus Anda terhadap BambooNode setelah perubahan kebijakan ini merupakan penerimaan Anda terhadap kebijakan yang diperbarui.
