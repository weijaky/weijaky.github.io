BambooNode 私隱政策

更新日期： 2026年7月26日

生效日期： 2026年7月26日

1. 簡介

BambooNode（中文名稱：竹節筆記，"我們"或"本應用"）是一款為Android設備開發的筆記和文件管理應用。本私隱政策旨在說明我們如何收集、使用和保護您在使用本應用時的個人資訊。

我們致力於保護您的私隱並確保您數據的安全。本政策適用於所有BambooNode用戶。

2. 我們收集哪些資訊？

BambooNode是一款注重私隱的應用。未經您的明確知情和同意，我們不會收集任何個人資訊。

2.1 本地數據

您使用BambooNode創建或導入的所有筆記和文件都存儲在您的設備本地。這包括：

  • 筆記的文本內容
  • 您添加到筆記中的圖片和附件
  • 文件元數據（名稱、大小、修改日期）
  • 用於組織筆記的標籤資訊
  • 應用設定和偏好設定

這些數據存儲在您設備的存儲空間中（下載文件夾或其他選定位置），絕不會傳輸到我們的服務器。

2.2 可選的Git同步數據

如果您啟用了可選的Git同步功能，您的筆記和文件可能會上載到您配置的遠程Git倉庫。這完全由您自行決定，並需要您提供：

  • 遠程倉庫URL
  • 認證憑據（使用者名稱/密碼或訪問令牌）

您的Git憑據使用Android的安全偏好設定存儲在設備本地，絕不會傳輸到我們的服務器。

2.3 設備資訊（用於故障排除）

當您使用反饋功能時，您可以選擇提供設備資訊以幫助我們排查問題。這可能包括：

  • Android版本
  • 設備型號
  • 應用版本

這些資訊僅在您明確提交反饋時發送，且僅用於改進應用。

3. 我們如何使用您的資訊？

我們僅將您的資訊用於以下目的：

  • 提供和維護BambooNode的核心功能
  • 實現筆記和文件的本地存儲與管理
  • 支持可選的Git同步功能（如果啟用）
  • 根據提供的反饋改進應用
  • 確保您數據的安全和完整性

4. 數據存儲與安全

4.1 本地存儲

您的筆記和文件存儲在您的Android設備本地。您可以在初始設定時選擇存儲位置（如下載文件夾）。

4.2 安全措施

我們實施合理的安全措施來保護您的數據，包括：

  • 使用Android的加密偏好設定安全存儲Git憑據
  • 使用Android的存儲訪問框架（SAF）進行安全的文件操作
  • 定期更新以解決安全漏洞

然而，沒有任何存儲方法是完全安全的。我們無法保證您數據的絕對安全性。

5. 數據共享

我們不會出於任何目的向第三方共享、出售或出租您的個人資訊。

唯一的例外是當您啟用Git同步時，您的數據會傳輸到您指定的遠程Git倉庫。我們無法控制第三方Git提供商如何處理您的數據。

6. 權限說明

BambooNode需要以下權限才能正常運行：

  • INTERNET： 用於Git同步和反饋功能
  • READ_EXTERNAL_STORAGE： 用於讀取設備上的筆記和文件
  • WRITE_EXTERNAL_STORAGE： 用於保存筆記和文件到設備
  • MANAGE_EXTERNAL_STORAGE： 用於在Android 11+上完全訪問外部存儲

所有權限均在運行時請求，您可以隨時通過設備設定撤銷權限。但是，撤銷某些權限可能會影響應用的功能。

7. 您的權利

您對自己的數據擁有以下權利：

  • 訪問權： 您可以通過應用直接訪問所有筆記和文件
  • 修改權： 您可以隨時編輯、重命名或刪除筆記和文件
  • 導出權： 您的筆記存儲為標準Markdown（.md）或文本（.txt）文件，可使用任何文件管理器導出
  • 刪除權： 您可以通過卸載應用並從設備中刪除文件來刪除所有數據

8. 歐盟通用數據保護條例（GDPR）合規聲明

BambooNode 遵守歐盟通用數據保護條例（GDPR），以保護歐盟和歐洲經濟區（EEA）用戶的個人數據權利。

8.1 數據控制者

BambooNode 作為通過本應用處理的任何個人數據的數據控制者。數據控制者負責確保您的個人數據按照 GDPR 的規定進行處理。

8.2 處理的法律依據

我們基於以下法律依據處理您的個人數據：

  • 同意：當您通過反饋功能明確提供設備資訊以用於故障排除時
  • 合同必要性：當您使用 Git 同步功能時，我們處理必要的數據以提供您請求的服務
  • 合法利益：我們可能處理匿名使用數據以改善應用穩定性和用戶體驗

8.3 數據保留

您的本地數據（筆記、文件、設定）將保留在您的設備上，直到您選擇刪除它們或卸載應用。反饋數據（如有）僅在解決報告問題所需的時間內保留，之後將被刪除。

8.4 國際數據傳輸

如果您啟用 Git 同步功能，您的數據可能會被傳輸到位於歐盟/歐洲經濟區以外的服務器。我們不對第三方 Git 提供商的數據處理實踐負責。請在啟用同步前查看您選擇的 Git 提供商的私隱政策。

8.5 歐盟/歐洲經濟區用戶的額外權利

除第 7 章列出的權利外，歐盟/歐洲經濟區用戶根據 GDPR 還享有以下權利：

  • 更正權：您可以要求更正不準確的個人數據
  • 刪除權（"被遺忘權"）：您可以要求刪除您的個人數據
  • 限制處理權：您可以要求我們限制對您個人數據的處理
  • 數據可攜帶權：您可以以結構化、機器可讀的格式接收您的個人數據
  • 反對權：您可以反對基於合法利益處理您的個人數據
  • 撤回同意權：您可以隨時撤回同意，且不影響撤回前基於同意的處理合法性

如需行使這些權利，請聯絡 weijaky@gmail.com。我們將按照 GDPR 要求在 30 天內回覆您的請求。

8.6 監管機構

如果您認為我們對您個人數據的處理侵犯了 GDPR，您有權向您所在地的監管機構或您居住地的監管機構提出投訴。

9. 私隱政策的變更

我們可能會不時更新本私隱政策。我們將通過在本頁面發佈新的私隱政策並更新"更新日期"來通知您任何變更。

在本政策變更後繼續使用BambooNode即表示您接受更新後的政策。
