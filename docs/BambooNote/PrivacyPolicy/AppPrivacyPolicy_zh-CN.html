Bamboo Note 隐私政策

更新日期： 2026年7月26日

生效日期： 2026年7月26日

1. 简介

Bamboo Note（"我们"或"本应用"）是一款为Android设备开发的笔记和文件管理应用。本隐私政策旨在说明我们如何收集、使用和保护您在使用本应用时的个人信息。

我们致力于保护您的隐私并确保您数据的安全。本政策适用于所有Bamboo Note用户。

2. 我们收集哪些信息？

Bamboo Note是一款注重隐私的应用。未经您的明确知情和同意，我们不会收集任何个人信息。

2.1 本地数据

您使用Bamboo Note创建或导入的所有笔记和文件都存储在您的设备本地。这包括：

  • 笔记的文本内容
  • 您添加到笔记中的图片和附件
  • 文件元数据（名称、大小、修改日期）
  • 用于组织笔记的标签信息
  • 应用设置和偏好设置

这些数据存储在您设备的存储空间中（下载文件夹或其他选定位置），绝不会传输到我们的服务器。

2.2 可选的Git同步数据

如果您启用了可选的Git同步功能，您的笔记和文件可能会上传到您配置的远程Git仓库。这完全由您自行决定，并需要您提供：

  • 远程仓库URL
  • 认证凭据（用户名/密码或访问令牌）

您的Git凭据使用Android的安全偏好设置存储在设备本地，绝不会传输到我们的服务器。

2.3 设备信息（用于故障排除）

当您使用反馈功能时，您可以选择提供设备信息以帮助我们排查问题。这可能包括：

  • Android版本
  • 设备型号
  • 应用版本

这些信息仅在您明确提交反馈时发送，且仅用于改进应用。

3. 我们如何使用您的信息？

我们仅将您的信息用于以下目的：

  • 提供和维护Bamboo Note的核心功能
  • 实现笔记和文件的本地存储与管理
  • 支持可选的Git同步功能（如果启用）
  • 根据提供的反馈改进应用
  • 确保您数据的安全和完整性

4. 数据存储与安全

4.1 本地存储

您的笔记和文件存储在您的Android设备本地。您可以在初始设置时选择存储位置（如下载文件夹）。

4.2 安全措施

我们实施合理的安全措施来保护您的数据，包括：

  • 使用Android的加密偏好设置安全存储Git凭据
  • 使用Android的存储访问框架（SAF）进行安全的文件操作
  • 定期更新以解决安全漏洞

然而，没有任何存储方法是完全安全的。我们无法保证您数据的绝对安全性。

5. 数据共享

我们不会出于任何目的向第三方共享、出售或出租您的个人信息。

唯一的例外是当您启用Git同步时，您的数据会传输到您指定的远程Git仓库。我们无法控制第三方Git提供商如何处理您的数据。

6. 权限说明

Bamboo Note需要以下权限才能正常运行：

  • INTERNET： 用于Git同步和反馈功能
  • READ_EXTERNAL_STORAGE： 用于读取设备上的笔记和文件
  • WRITE_EXTERNAL_STORAGE： 用于保存笔记和文件到设备
  • MANAGE_EXTERNAL_STORAGE： 用于在Android 11+上完全访问外部存储

所有权限均在运行时请求，您可以随时通过设备设置撤销权限。但是，撤销某些权限可能会影响应用的功能。

7. 您的权利

您对自己的数据拥有以下权利：

  • 访问权： 您可以通过应用直接访问所有笔记和文件
  • 修改权： 您可以随时编辑、重命名或删除笔记和文件
  • 导出权： 您的笔记存储为标准Markdown（.md）或文本（.txt）文件，可使用任何文件管理器导出
  • 删除权： 您可以通过卸载应用并从设备中删除文件来删除所有数据

8. 欧盟通用数据保护条例（GDPR）合规声明

Bamboo Note 遵守欧盟通用数据保护条例（GDPR），以保护欧盟和欧洲经济区（EEA）用户的个人数据权利。

8.1 数据控制者

Bamboo Note 作为通过本应用处理的任何个人数据的数据控制者。数据控制者负责确保您的个人数据按照 GDPR 的规定进行处理。

8.2 处理的法律依据

我们基于以下法律依据处理您的个人数据：

  • 同意：当您通过反馈功能明确提供设备信息以用于故障排除时
  • 合同必要性：当您使用 Git 同步功能时，我们处理必要的数据以提供您请求的服务
  • 合法利益：我们可能处理匿名使用数据以改善应用稳定性和用户体验

8.3 数据保留

您的本地数据（笔记、文件、设置）将保留在您的设备上，直到您选择删除它们或卸载应用。反馈数据（如有）仅在解决报告问题所需的时间内保留，之后将被删除。

8.4 国际数据传输

如果您启用 Git 同步功能，您的数据可能会被传输到位于欧盟/欧洲经济区以外的服务器。我们不对第三方 Git 提供商的数据处理实践负责。请在启用同步前查看您选择的 Git 提供商的隐私政策。

8.5 欧盟/欧洲经济区用户的额外权利

除第 7 章列出的权利外，欧盟/欧洲经济区用户根据 GDPR 还享有以下权利：

  • 更正权：您可以要求更正不准确的个人数据
  • 删除权（"被遗忘权"）：您可以要求删除您的个人数据
  • 限制处理权：您可以要求我们限制对您个人数据的处理
  • 数据可携带权：您可以以结构化、机器可读的格式接收您的个人数据
  • 反对权：您可以反对基于合法利益处理您的个人数据
  • 撤回同意权：您可以随时撤回同意，且不影响撤回前基于同意的处理合法性

如需行使这些权利，请联系 weijaky@gmail.com。我们将按照 GDPR 要求在 30 天内回复您的请求。

8.6 监管机构

如果您认为我们对您个人数据的处理侵犯了 GDPR，您有权向您所在地的监管机构或您居住地的监管机构提出投诉。

9. 隐私政策的变更

我们可能会不时更新本隐私政策。我们将通过在本页面发布新的隐私政策并更新"更新日期"来通知您任何变更。

在本政策变更后继续使用Bamboo Note即表示您接受更新后的政策。
