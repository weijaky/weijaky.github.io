Bamboo Note 隱私政策

更新日期： 2026年7月26日

生效日期： 2026年7月26日

1. 簡介

Bamboo Note（"我們"或"本應用"）是一款為Android裝置開發的筆記和檔案管理應用。本隱私政策旨在說明我們如何收集、使用和保護您在使用本應用時的個人資訊。

我們致力於保護您的隱私並確保您資料的安全。本政策適用於所有Bamboo Note使用者。

2. 我們收集哪些資訊？

Bamboo Note是一款注重隱私的應用。未經您的明確知情和同意，我們不會收集任何個人資訊。

2.1 本機資料

您使用Bamboo Note建立或匯入的所有筆記和檔案都儲存在您的裝置本機。這包括：

  • 筆記的文字內容
  • 您新增到筆記中的圖片和附件
  • 檔案中繼資料（名稱、大小、修改日期）
  • 用於組織筆記的標籤資訊
  • 應用設定和偏好設定

這些資料儲存在您裝置的儲存空間中（下載資料夾或其他選定位置），絕不會傳輸到我們的伺服器。

2.2 可選的Git同步資料

如果您啟用了可選的Git同步功能，您的筆記和檔案可能會上傳到您設定的遠端Git儲存庫。這完全由您自行決定，並需要您提供：

  • 遠端儲存庫URL
  • 認證憑據（使用者名稱/密碼或存取權杖）

您的Git憑據使用Android的安全偏好設定儲存在裝置本機，絕不會傳輸到我們的伺服器。

2.3 裝置資訊（用於故障排除）

當您使用意見回饋功能時，您可以選擇提供裝置資訊以幫助我們排查問題。這可能包括：

  • Android版本
  • 裝置型號
  • 應用版本

這些資訊僅在您明確提交意見回饋時傳送，且僅用於改進應用。

3. 我們如何使用您的資訊？

我們僅將您的資訊用於以下目的：

  • 提供和維護Bamboo Note的核心功能
  • 實現筆記和檔案的本機儲存與管理
  • 支援可選的Git同步功能（如果啟用）
  • 根據提供的意見回饋改進應用
  • 確保您資料的安全和完整性

4. 資料儲存與安全

4.1 本機儲存

您的筆記和檔案儲存在您的Android裝置本機。您可以在初始設定時選擇儲存位置（如下載資料夾）。

4.2 安全措施

我們實施合理的安全措施來保護您的資料，包括：

  • 使用Android的加密偏好設定安全儲存Git憑據
  • 使用Android的儲存存取框架（SAF）進行安全的檔案操作
  • 定期更新以解決安全漏洞

然而，沒有任何儲存方法是完全安全的。我們無法保證您資料的絕對安全性。

5. 資料分享

我們不會出於任何目的向第三方分享、出售或出租您的個人資訊。

唯一的例外是當您啟用Git同步時，您的資料會傳輸到您指定的遠端Git儲存庫。我們無法控制第三方Git提供者如何處理您的資料。

6. 權限說明

Bamboo Note需要以下權限才能正常執行：

  • INTERNET： 用於Git同步和意見回饋功能
  • READ_EXTERNAL_STORAGE： 用於讀取裝置上的筆記和檔案
  • WRITE_EXTERNAL_STORAGE： 用於儲存筆記和檔案到裝置
  • MANAGE_EXTERNAL_STORAGE： 用於在Android 11+上完整存取外部儲存

所有權限均在執行時請求，您可以隨時透過裝置設定撤銷權限。但是，撤銷某些權限可能會影響應用的功能。

7. 您的權利

您對自己的資料擁有以下權利：

  • 存取權： 您可以透過應用直接存取所有筆記和檔案
  • 修改權： 您可以隨時編輯、重新命名或刪除筆記和檔案
  • 匯出權： 您的筆記儲存為標準Markdown（.md）或文字（.txt）檔案，可使用任何檔案管理員匯出
  • 刪除權： 您可以透過解除安裝應用並從裝置中刪除檔案來刪除所有資料

8. 歐盟通用資料保護規則（GDPR）合規聲明

Bamboo Note 遵守歐盟通用資料保護規則（GDPR），以保護歐盟和歐洲經濟區（EEA）使用者的個人資料權利。

8.1 資料控制者

Bamboo Note 作為透過本應用處理的任何個人資料的資料控制者。資料控制者負責確保您的個人資料按照 GDPR 的規定進行處理。

8.2 處理的法律依據

我們基於以下法律依據處理您的個人資料：

  • 同意：當您透過意見回饋功能明確提供裝置資訊以用於故障排除時
  • 合約必要性：當您使用 Git 同步功能時，我們處理必要的資料以提供您請求的服務
  • 合法利益：我們可能處理匿名使用資料以改善應用穩定性和使用者體驗

8.3 資料保留

您的本機資料（筆記、檔案、設定）將保留在您的裝置上，直到您選擇刪除它們或解除安裝應用。意見回饋資料（如有）僅在解決報告問題所需的時間內保留，之後將被刪除。

8.4 國際資料傳輸

如果您啟用 Git 同步功能，您的資料可能會被傳輸到位於歐盟/歐洲經濟區以外的伺服器。我們不對第三方 Git 提供者的資料處理實踐負責。請在啟用同步前檢視您選擇的 Git 提供者的隱私政策。

8.5 歐盟/歐洲經濟區使用者的額外權利

除第 7 章列出的權利外，歐盟/歐洲經濟區使用者根據 GDPR 還享有以下權利：

  • 更正權：您可以要求更正不準確的個人資料
  • 刪除權（「被遺忘權」）：您可以要求刪除您的個人資料
  • 限制處理權：您可以要求我們限制對您個人資料的處理
  • 資料可攜帶權：您可以以結構化、機器可讀的格式接收您的個人資料
  • 反對權：您可以反對基於合法利益處理您的個人資料
  • 撤回同意權：您可以隨時撤回同意，且不影響撤回前基於同意的處理合法性

如需行使這些權利，請聯絡 weijaky@gmail.com。我們將按照 GDPR 要求在 30 天內回覆您的請求。

8.6 監管機關

如果您認為我們對您個人資料的處理侵犯了 GDPR，您有權向您所在地的監管機關或您居住地的監管機關提出申訴。

9. 隱私政策的變更

我們可能會不定期更新本隱私政策。我們將透過在本頁面發布新的隱私政策並更新「更新日期」來通知您任何變更。

在本政策變更後繼續使用Bamboo Note即表示您接受更新後的政策。
